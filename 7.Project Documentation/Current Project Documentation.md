# Current Project Documentation

## Project Overview
This repository is a starter template for an AI, ML, or Generative AI project. It includes project folders for each development phase and a simple Node.js app that can be run locally.

## How to Run
1. Open the terminal in the project folder.
2. Run the following command:
   ```bash
   npm start
   ```
3. Open the local URL shown in the terminal.

## Current Application Features
- Local web server
- HTML landing page
- Status API endpoint at `/api/status`
